# Data Directory

This directory contains all data for the PathoMap application.

## Directory Structure

```
data/
├── README.md                              # This file
├── pathomap-dataset.json                  # Main production dataset (generated)
├── sample-dataset.json                    # Sample dataset for testing (5 pathogens)
├── pathomap.db                            # SQLite database (generated)
├── schema.sql                             # SQL schema definition (generated)
├── classification-mapping.json           # Classification mappings for categorization
├── schema/                                # JSON Schema definitions
│   └── pathogens.schema.json             # Schema validation for pathogens dataset
└── sources/                               # Source data for build pipeline
    ├── curated_data.json               # Curated pathogen data (manually maintained)
    ├── effectors_seed.json               # Effector data
    ├── host_proteins_seed.json           # Host protein reference data
    ├── pathogen_overrides.json           # Manual overrides for NCBI lookups
    └── ncbi/                             # NCBI API cache
        ├── genomes/                      # Genome assembly data from NCBI Datasets
        ├── taxonomy/                     # Taxonomy lineage data
        └── taxonomy_search/              # Search results for name-to-tax_id resolution
```

## Production Data Files

These files are generated by `scripts/build_pathogens.py` and should not be edited manually.

- **pathomap-dataset.json**: The main dataset containing all pathogens with enriched NCBI taxonomy and genome data. Used by the v2 application.
- **sample-dataset.json**: A smaller sample with 5 pathogens for testing and demos.
- **pathomap.db**: SQLite database with the same data as pathomap-dataset.json.
- **schema.sql**: SQL schema definition for the pathogens table.

## Classification Mappings

- **classification-mapping.json**: Maps host targets, effector types, and mechanisms to standardized categories. Used for categorization in the application.

## Source Data

The `sources/` directory contains the raw data used to build the production dataset.

### Manually Curated Files

- **curated_data.json**: Curated base pathogen data. This is the primary source of truth for pathogen information.
- **effectors_seed.json**: Effector data linked to pathogens.
- **host_proteins_seed.json**: Host protein reference data.
- **pathogen_overrides.json**: Manual overrides for specific NCBI lookups (e.g., pinned genome accessions for specific strains).

### NCBI Cache

The `ncbi/` directory contains cached responses from NCBI APIs to avoid repeated network calls. These are automatically generated by the build script.

- **genomes/**: Genome assembly data from NCBI Datasets API. Files are named `{pathogen_id}-{tax_id}.json` or `{pathogen_id}-{tax_id}-refseq.json` (for RefSeq-specific queries).
- **taxonomy/**: Taxonomy lineage data from NCBI Taxonomy database. Files are named `{tax_id}.json`.
- **taxonomy_search/**: Search results from NCBI E-utilities API to resolve pathogen names to tax IDs. Files are named `{pathogen_id}-{sanitized-name}.json`.

## Building the Dataset

To regenerate the production dataset from the source files:

```bash
python scripts/build_pathogens.py
```

Options:
- `--check`: Validate the current dataset without rebuilding
- `--refresh`: Refresh NCBI cache (force API calls)
- `--no-network`: Use only cached NCBI data (no API calls)

See `scripts/build_pathogens.py` for more details.
